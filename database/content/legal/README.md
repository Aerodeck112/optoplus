# Texte juridice — proiecte

Proiecte redactate la cererea Optoplus (01.11.2026), pe baza datelor firmei din registrul public ANAF și a regulilor
comerciale confirmate (livrare 22 lei în România, plată card BT iPay / transfer / ramburs, execuție 2–5 zile
lucrătoare). Se încarcă în CMS ca **ciorne** și se publică numai după verificare (permisiunea `cms.legal`).

Marcajele `{firma}`, `{cui}` etc. se completează din Setări la încărcare. Nu sunt consultanță juridică:
textele trebuie verificate de Optoplus (și, ideal, de un jurist), mai ales clauzele marcate „DE VERIFICAT”.
